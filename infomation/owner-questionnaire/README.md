# Owner questionnaire — ready to build in Google Forms

This package contains **270 detailed question entries across five staged forms**, plus setup instructions and a response-review template. It is tailored to the clothing-store/theme project and its three storefront references.

## Build and send in this order

| File | What it covers | Questions |
|---|---|---:|
| [Builder guide](00-google-forms-builder-guide.md) | Setup, branching, required fields, phone preview, response handling | — |
| [Form 1](01-business-brand-and-customers.md) | Business goals, brand position, customers, reuse | 50 |
| [Form 2](02-visual-direction-and-content.md) | References, assets, layouts, header, animations, content | 54 |
| [Form 3](03-shopping-experience.md) | Navigation, cards, filters, products, sizes, cart, phone journeys | 70 |
| [Form 4](04-catalog-operations-and-integrations.md) | Migration, catalog, stock, markets, payments, delivery, apps, editing | 60 |

| [Response-review template](06-response-review-template.md) | Turn submitted answers into an actionable approved brief | — |

Each question has a stable ID, suggested field type, required/optional flag, choices where useful, and help text. Copy the title/description/choices into Google Forms; omit the internal type/flag notation from the visible question text.

The owner can answer Not sure—recommend rather than inventing details. Completing the forms is discovery, not automatic approval of every feature or cost. Final scope is established by reviewing the priorities and dependencies together.

Five forms allow several sessions and keep the deep question bank usable. If you prefer one form, the builder guide explains the tradeoff. It also gives the one optional existing-store routing path and notes which Google Forms question types support routing.

The review template references the existing theme plan in the parent folder. Use the copy inside NKIL for those links; a standalone questionnaire export may be used without the parent plan.
